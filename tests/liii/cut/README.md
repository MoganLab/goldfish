# (liii cut) 模块函数分类索引

`cut` 和 `cute` 是 SRFI-26 提供的宏，用于创建部分应用（Partial Application）函数。
它们允许预先填充函数的部分参数，留下参数位置待后续传入。

核心用途：在不使用 `lambda` 的情况下快速创建函数闭包，适用于函数式编程中的参数预设。

## 常见用法示例

```scheme
(import (liii cut))

;; 示例1：预设函数的第一个参数
((cut + 10 <>) 5) ; => 15

;; 示例2：预设函数的中间参数
((cut list 'a <> 'c) 'b) ; => (a b c)

;; 示例3：使用多个占位符
((cut list <> <>) 'x 'y) ; => (x y)

;; 示例4：结合可变参数
((cut + 1 <...>) 2 3 4) ; => 10
((cut <> 1 <...>) + 2 3) ; => 6
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
gf doc "函数名"
```
或者指定库名：
```bash
gf doc liii/cut "函数名"
```
