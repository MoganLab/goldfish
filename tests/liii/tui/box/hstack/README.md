# (liii tui box hstack) 模块函数索引

`(liii tui box hstack)` 提供水平分列排版组件，支持多子组件横向并排、自定义列宽分配（均分/比例/混排）、列间距与多行对齐。

使用时导入：

```scheme
(import (liii tui box hstack))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc make-hstack
```

## 函数分类索引

### 水平布局组件与谓词
- `make-hstack` - 创建水平分列排版组件
- `hstack?` - 判断是否为水平分列组件
