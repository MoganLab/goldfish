# (liii tui loader spinner) 模块函数索引

`(liii tui loader spinner)` 提供微调器（spinner/loader）组件的构造与谓词，包装为标准 TUI component 并支持单行文本渲染、前缀后缀附加及宽度截断。

使用时导入：

```scheme
(import (liii tui loader spinner))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc make-spinner
```

## 函数分类索引

### 微调器组件构建与谓词
- `make-spinner` - 创建微调器组件
- `spinner?` - 判断是否为微调器实例
- `make-loader` - 创建微调器组件（别名）
- `loader?` - 判断是否为加载器实例（别名）
