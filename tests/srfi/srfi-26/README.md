# (srfi srfi-26) 模块函数分类索引

SRFI-26 提供「切」（cut）与「可爱」（cute）两个部分应用宏，
用于在不使用 `lambda` 的前提下快速构造参数预设后的函数闭包。

- `cut` 中的非占位符表达式延迟到调用时求值，每次调用都会重新求值。
- `cute` 中的非占位符表达式在过程创建时立即求值一次并局部绑定。

## 常见用法示例

```scheme
(import (srfi srfi-26))

;; 示例1：预设函数的第一个参数
((cut + 10 <>) 5) ; => 15

;; 示例2：预设函数的中间参数
((cut list 'a <> 'c) 'b) ; => (a b c)

;; 示例3：收集剩余参数
((cut + 1 <...>) 2 3 4) ; => 10

;; 示例4：创建时立即求值
((cute + 1 <...>) 2 3 4) ; => 10
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
gf doc "函数名"
```
或者指定库名：
```bash
gf doc srfi/srfi-26 "函数名"
```

## 函数分类索引

### 一、部分应用宏
- `cut` - 延迟求值的部分应用，非占位符表达式在每次调用时求值
- `cute` - 立即求值的部分应用，非占位符表达式在过程创建时求值
