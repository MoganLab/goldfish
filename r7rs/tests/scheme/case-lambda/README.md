# (scheme case-lambda) 模块函数分类索引

R7RS `scheme case-lambda` 提供基于参数数量的函数重载机制，允许一个函数根据不同数量的参数执行不同的逻辑。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
gf doc "函数名"
```
或者指定库名：
```bash
gf doc scheme/case-lambda "函数名"
```
