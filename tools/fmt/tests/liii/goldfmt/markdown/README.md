# (liii goldfmt markdown) 模块函数分类索引

Markdown 格式化：通过 cmark domain 的 Markdown -> md-stem -> Markdown 往返转换统一排版，支持表格列宽和中文显示宽度对齐。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc "函数名"
```
