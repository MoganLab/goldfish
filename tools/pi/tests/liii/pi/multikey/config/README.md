# (liii pi multikey config) 模块函数分类索引

`(liii pi multikey config)` 提供 multikey 扩展的 config augmenter：命中密钥池时向会话配置注入密钥与轮换钩子。

使用时导入：

```scheme
(import (liii pi multikey config))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-multikey-augment-config
```
