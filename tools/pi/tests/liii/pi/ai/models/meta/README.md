# (liii pi ai models meta) 模块函数索引

`(liii pi ai models meta)` 提供模型元数据的查找与动态解析，支持环境变量重载、供应商默认端点规范化以及模型规格 record 构建。

使用时导入：

```scheme
(import (liii pi ai models meta))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-resolve-model-metadata
```

- `pi-resolve-model-metadata` - 解析指定模型的规格与端点元数据
