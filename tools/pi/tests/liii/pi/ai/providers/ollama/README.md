# (liii pi ai providers ollama) 模块函数索引

`(liii pi ai providers ollama)` 提供 Ollama 本地模型服务商的基础配置与内置推荐模型列表。

使用时导入：

```scheme
(import (liii pi ai providers ollama))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc PI_OLLAMA_PROVIDER
```

## 函数分类索引

### 服务商配置与模型定义
- `PI_OLLAMA_PROVIDER` - Ollama 服务商基础配置
- `PI_OLLAMA_BUILTIN_MODELS` - Ollama 内置模型定义列表
