# (liii pi review format) 模块函数分类索引

`(liii pi review format)` 提供代码审查发现问题列表的 Markdown 格式化能力。

使用时导入：

```scheme
(import (liii pi review format))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-format-review-findings
```

## 函数分类索引

### 审查结果格式化
- `pi-format-review-findings` - 将审查发现的问题列表格式化为易读的 Markdown 文本展示
