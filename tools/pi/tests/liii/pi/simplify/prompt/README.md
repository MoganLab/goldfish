# (liii pi simplify prompt) 模块函数分类索引

`(liii pi simplify prompt)` 提供用于代码简化流程的提示词构建能力，分别支持只读建议模式与应用修改模式。

使用时导入：

```scheme
(import (liii pi simplify prompt))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-build-simplify-prompt
gf doc pi-build-simplify-apply-prompt
```

## 函数分类索引

### 提示词构建
- `pi-build-simplify-prompt` - 构建只读模式下的代码简化提示词
- `pi-build-simplify-apply-prompt` - 构建应用修改模式下的代码简化提示词
