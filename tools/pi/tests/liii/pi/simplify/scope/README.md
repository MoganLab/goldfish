# (liii pi simplify scope) 模块函数分类索引

`(liii pi simplify scope)` 提供代码简化目标范围与行区间的格式化与描述构建功能。

使用时导入：

```scheme
(import (liii pi simplify scope))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-build-scope-lines
gf doc pi-format-range
```

## 函数分类索引

### 范围格式化
- `pi-build-scope-lines` - 根据变更文件列表生成用于提示词的 Scope 描述行
- `pi-format-range` - 将起止行号范围格式化为行号或区间字符串
