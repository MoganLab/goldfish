# (liii pi simplify format) 模块函数分类索引

`(liii pi simplify format)` 提供代码简化建议列表的展示格式化能力，将结构化的建议数据转换为易读的 Markdown 文本。

使用时导入：

```scheme
(import (liii pi simplify format))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-format-simplify-suggestions
```

## 函数分类索引

### 建议格式化
- `pi-format-simplify-suggestions` - 将代码简化建议列表格式化为易读的 Markdown 文本展示
