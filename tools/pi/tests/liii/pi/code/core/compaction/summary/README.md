# (liii pi code core compaction summary) 模块函数分类索引

`(liii pi code core compaction summary)` 提供压缩摘要生成能力。

使用时导入：

```scheme
(import (liii pi code core compaction summary))
```

## 查看函数文档

```bash
gf doc pi-summarization-failure
gf doc pi-generate-summary
```

## 函数分类索引

### 摘要生成
- `pi-summarization-failure` - 根据模型响应生成压缩摘要失败的错误描述
- `pi-generate-summary` - 调用模型生成会话压缩摘要
