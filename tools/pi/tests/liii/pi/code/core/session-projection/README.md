# (liii pi code core session-projection) 模块函数分类索引

`(liii pi code core session-projection)` 提供会话条目到上下文投影的构建与解析能力。

使用时导入：

```scheme
(import (liii pi code core session-projection))
```

## 子库导览

- `state/` - 投影状态汇总
- `context-edit/` - 上下文编辑应用

## 查看函数文档

```bash
gf doc pi-session-path
gf doc pi-context-entries
gf doc pi-build-session-projection
```

## 函数分类索引

### 投影构建
- `pi-session-path` - 构建会话条目路径
- `pi-context-entries` - 解析会话条目为上下文条目
- `pi-build-session-projection` - 构建完整的会话投影
