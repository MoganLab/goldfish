# (liii pi code core extensions types) 模块函数分类索引

`(liii pi code core extensions types)` 聚合重导出扩展注册表、API、上下文与各类扩展定义的类型接口。

使用时导入：

```scheme
(import (liii pi code core extensions types))
```

## 子库导览

- `types/core/` - 扩展注册表、API 与上下文记录类型
- `types/defs/` - 工具、标志、命令与流程定义记录类型

## 查看函数文档

```bash
gf doc make-extension-registry
gf doc make-extension-tool-def
```
