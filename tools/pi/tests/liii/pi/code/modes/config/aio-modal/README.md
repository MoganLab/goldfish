# (liii pi code modes config aio-modal) 模块函数分类索引

`(liii pi code modes config aio-modal)` 提供 `all-in-one` 子标签页的新建链条与添加槽位覆盖层状态机。

## 使用方法

```scheme
(import (liii pi code modes config aio-modal))
```

## 函数列表

- `pi-config-aio-modal-new-chain` - 构造新建链条输入覆盖层
- `pi-config-aio-modal-slot-picker` - 构造供应商/模型/思考强度槽位选择覆盖层
- `pi-config-aio-modal-thinking-picker` - 构造调整已有槽位思考强度的选择覆盖层
- `pi-config-aio-modal-step` - 处理覆盖层按键步进
