# (liii pi code modes config overlay) 模块函数分类索引

`(liii pi code modes config overlay)` 提供配置视图只读覆盖层的渲染与按键处理能力。

使用时导入：

```scheme
(import (liii pi code modes config overlay))
```

## 查看函数文档

```bash
gf doc pi-config-render-overlay
gf doc pi-config-overlay-step
```

## 函数分类索引

### 只读覆盖层
- `pi-config-render-overlay` - 渲染配置文件的只读覆盖层
- `pi-config-overlay-step` - 处理只读覆盖层上的按键
