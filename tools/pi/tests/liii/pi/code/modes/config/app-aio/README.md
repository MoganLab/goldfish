# (liii pi code modes config app-aio) 模块函数分类索引

`(liii pi code modes config app-aio)` 提供 `all-in-one` 子标签页的导航按键与设默认交互逻辑。

## 使用方法

```scheme
(import (liii pi code modes config app-aio))
```

## 函数列表

- `pi-config-aio-key-handler` - 处理 all-in-one 子标签页的链条与节点导航按键
- `pi-config-aio-enter` - 在 all-in-one 子标签页将选中链条设为默认模型
- `pi-config-aio-action` - 判定 all-in-one 子标签页按键触发的交互动作
- `pi-config-aio-modal-handle` - 处理 all-in-one 交互覆盖层按键并执行写入
- `pi-config-aio-exec-action` - 执行 all-in-one 子标签页交互动作
