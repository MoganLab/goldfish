# (liii pi code modes config aio-writes) 模块函数分类索引

`(liii pi code modes config aio-writes)` 提供 `all-in-one` 子标签页的链条与槽位增删改写入计划。

## 使用方法

```scheme
(import (liii pi code modes config aio-writes))
```

## 函数列表

- `pi-config-aio-add-chain` - 生成追加新伪模型链条的写入计划
- `pi-config-aio-add-slot` - 生成向链条追加新槽位的写入计划
- `pi-config-aio-delete-chain` - 生成删除指定伪模型链条的写入计划
- `pi-config-aio-delete-slot` - 生成删除指定槽位的写入计划
- `pi-config-aio-set-slot-thinking` - 生成修改指定槽位思考强度的写入计划
- `pi-config-aio-promote-slot` - 将指定槽位置为链条第一个节点
