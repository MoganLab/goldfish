# (liii pi code modes interactive app-tool-timer) 模块函数索引

`(liii pi code modes interactive app-tool-timer)` 提供运行中 bash 工具卡片 `Elapsed` 计时器的节拍推进与重绘调度逻辑。

使用时导入：

```scheme
(import (liii pi code modes interactive app-tool-timer))
```

```bash
gf doc <函数名>
```
