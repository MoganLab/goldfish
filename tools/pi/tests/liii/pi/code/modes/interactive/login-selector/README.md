# (liii pi code modes interactive login-selector) 模块函数索引

`(liii pi code modes interactive login-selector)` 提供登录服务商选择器组件（Login Selector），支持展示服务商列表、配置状态与模糊搜索。

使用时导入：

```scheme
(import (liii pi code modes interactive login-selector))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc make-login-selector
```
