# (liii pi code modes interactive worker-emit) 模块函数索引

`(liii pi code modes interactive worker-emit)` 提供Worker 事件发射器，负责将会话事件转换并发送至 TUI 事件通道。

使用时导入：

```scheme
(import (liii pi code modes interactive worker-emit))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc <函数名>
```
