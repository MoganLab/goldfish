# (liii pi code modes interactive app-history) 模块函数索引

`(liii pi code modes interactive app-history)` 提供会话历史重建能力：把目标会话当前有效分支的条目转换为可见的 TUI 卡片，并原子替换聊天区。

使用时导入：

```scheme
(import (liii pi code modes interactive app-history))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc <函数名>
```

## 函数分类索引

- 历史卡片构建：`pi-history-build-cards`
- 应用层历史重建：`pi-app-rebuild-history!`
