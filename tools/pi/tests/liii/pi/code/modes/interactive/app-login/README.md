# (liii pi code modes interactive app-login) 模块函数索引

`(liii pi code modes interactive app-login)` 提供 `/login` 交互式命令的调度、选择器与对话框状态流转以及凭证持久化。

使用时导入：

```scheme
(import (liii pi code modes interactive app-login))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-app-submit-login!
```
