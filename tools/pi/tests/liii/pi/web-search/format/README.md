# (liii pi web-search format) 模块函数分类索引

`(liii pi web-search format)` 提供联网搜索结果的展示格式化能力，将回答文本、grounding 引用与来源整理为统一的结构。

使用时导入：

```scheme
(import (liii pi web-search format))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-format-web-search-result
```

## 函数分类索引

### 结果格式化
- `pi-format-web-search-result` - 将联网搜索结果整理为回答文本、内容块与来源列表
