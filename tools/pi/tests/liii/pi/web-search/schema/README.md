# (liii pi web-search schema) 模块函数分类索引

`(liii pi web-search schema)` 提供 `web_search` 工具的 JSON Schema 定义与参数校验能力。

使用时导入：

```scheme
(import (liii pi web-search schema))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-web-search-schema
gf doc pi-validate-web-search-args
```

## 函数分类索引

### Schema 与校验
- `pi-web-search-schema` - 获取 web_search 工具的 JSON Schema 定义
- `pi-validate-web-search-args` - 校验 web_search 工具参数的合法性与取值范围
