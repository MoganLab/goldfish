## 验收点

- CLI 参数解析与别名支持：
  - 支持 `--no-tools` 开关，解析为 `(cons 'no-tools #t)`。
  - 支持 `--no-builtin-tools` 开关，行为与 `--no-tools` 完全等价。
  - 默认未指定时为 `#f`。
- 关闭优先策略（与 `--tools`、`--exclude-tools` 组合）：
  - 当指定 `--no-tools` 或 `--no-builtin-tools` 时，`resolve-active-tools` 返回 `'()`。
  - 组合优先级以关闭优先：无论同时指定了 `--tools` 还是 `--exclude-tools`，只要开启 `--no-tools`（或 `--no-builtin-tools`），有效工具集均为空列表 `'()`。
- API 请求体无 tools 字段与纯文本对话：
  - 当有效工具集为空列表时，请求体构造函数（如 Gemini 的 `gemini-build-request-body` 等）不输出 `"tools"`（及 `"toolConfig"`）字段。
  - 模型在纯文本模式下直接回复文本，不发起工具调用。
- 帮助文本与文档：
  - `bin/gf pi --help` 包含 `--no-tools` 与 `--no-builtin-tools` 的说明。
  - `PI_SPEC.md` 包含对应用法说明。
- 门禁检查与测试全绿：
  - `timeout 600 xmake b goldfish`
  - `timeout 120 bin/gf fmt`
  - `git diff --exit-code`
  - `timeout 120 bin/gf check`
  - `bin/gf doc --build-json`
  - 既有单元测试与相关新增测试全绿。

- 在 `tools/pi/liii/pi/args.scm` 中增加 `--no-tools` 与 `--no-builtin-tools` 开关处理。
- 在 `tools/pi/liii/pi/config.scm` 的 `resolve-active-tools` 中优先判断 `no-tools`，若为真直接返回 `'()`。
- 编写单元测试验证参数解析、配置解析及请求体构造逻辑。
- 更新帮助文本与 `PI_SPEC.md`。
