## 验收点

1.0 **集成 `(liii tui editor)` 输入组件**：
- 嵌入 `(liii tui editor)` 为 TUI 输入组件核心，支持单行/多行文本编辑缓冲；
- 维护 Prompt 输入提示符（如 `> `）与占位符（如 `Ask a question or type / for commands...`）；
- 具备焦点管理与文本提取/清空能力。

2.0 **完整按键映射与编辑能力**：
- 支持普通字符插入与中文 UTF-8 字符录入；
- 支持 Backspace 退格删除与 Delete 前向删除；
- 支持左右方向键（`'left` / `'right`）横向光标精确移动；
- 支持 `'home` 跳转至行首与 `'end` 跳转至行尾。

3.0 **会话历史记录导航（History Navigation）**：
- 当处于首行或输入框为空时，按向上箭头（`'up`）翻阅上一条历史输入；
- 按向下箭头（`'down`）翻阅下一条历史记录或恢复草稿；
- 提取并支持向历史记录堆栈追加已提交的 Prompt。

4.0 **多行折行与回车提交逻辑**：
- 默认按 `Enter` 提取完整输入内容并触发提交（触发状态流转至思考/执行）；
- 支持多行模式：按 `Shift+Enter`（或末尾反斜杠 `\` + Enter）产生换行，继续在下一行编辑。

5.0 **现代化外框包裹渲染与 TDD 覆盖**：
- 支持通过现代化边框（如圆角边框）或前缀高亮包裹输入框视图；
- 利用虚拟终端（VirtualTerminal）注入按键流验证字符输入、光标移动、折行与提交的确定性行为；
- 门禁四连：`timeout 600 xmake b goldfish`、`timeout 120 bin/gf fmt`、`git diff --exit-code`、`timeout 120 bin/gf check` 与相关单测 100% PASS。

## 2026-10-21 任务描述

### What

1. 依据 `Agents.md` §3 任务 083 验收点建立任务文档 `tools/pi/devel/083.md`；
2. 梳理 `(liii tui editor)` 的已有接口与能力（Buffer、Cursor、History、View、Component）；
3. 规划在 `tools/pi/liii/pi/modes/tui/` 下集成输入组件，定义按键调度、历史导航与多行提交行为。

### Why

终端 Agent 的人机交互核心在于 Prompt 的输入与编辑体验。借助底层 `(liii tui editor)` 库已有的丰富缓冲和光标控制能力，可无缝实现字符编辑、行内导航、多行排版与历史回顾，同时为任务 084（MainScreen 动态布局）与任务 089（Slash 命令悬浮菜单）提供坚实的底层组件支撑。

### How

- 利用 `(liii tui editor)` 提供的 `make-text-area` / `make-editor` / `buffer` 原语封装 `pi-tui-editor`；
- 在按键分发阶段拦截 Enter 与多行修饰符（如末尾带 `\` 或换行事件），区分普通换行与消息提交；
- 向上/向下键在光标位于顶行/底行时触发 `history-prev` / `history-next`，实现命令行沉浸式历史穿梭；
- 结合 VirtualTerminal 进行完整的无头输入测试，校验屏幕缓冲区的确切字符与光标位置。
