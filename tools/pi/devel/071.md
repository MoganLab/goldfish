## 验收点

从 `tools/pi/Agents.md` §3 任务表 071 提取并细化：

1. **分层扫描与目录约定发现（Discovery）**：
   - 扫描指定目录下的有效扩展入口：支持直接存放的 `*.scm` 文件，以及包含 `index.scm` 的子目录（如 `foo/index.scm`）；
   - 按四个层级有序发现插件：
     1) 仓库内置目录：`tools/pi/liii/pi/extensions/`；
     2) 用户全局目录：`~/.pi/agent/extensions/*.scm` 或 `~/.pi/agent/extensions/*/index.scm`（支持通过 `PI_CODING_AGENT_DIR` 重定向便于隔离测试）；
     3) 项目局部目录：当前工作区 `.pi/extensions/*.scm` 或 `.pi/extensions/*/index.scm`；
     4) 命令行显式指定：支持接收显式路径列表（来自 `-e, --extension <path.scm>`）；
   - 目录不存在或为空时安全返回空列表，不报错；同名/同路径去重与顺序稳定。
2. **扩展加载协议与工厂函数调用（Loader）**：
   - 支持标准的扩展文件契约：扩展文件可返回一个接受 `ExtensionAPI` 的工厂过程 `(lambda (api) ...)`，或顶层定义约定的入口过程；
   - 加载器调用工厂函数并注入 `ExtensionAPI` 实例，扩展可借此注册工具、参数、命令与监听事件；
   - 记录已加载扩展的元信息（路径、加载状态、耗时/错误原因）。
3. **单插件异常隔离与容错（Fault Tolerance）**：
   - 加载或执行扩展工厂函数出现语法错误、运行时异常或非法契约时，主进程绝不崩溃；
   - 捕获异常后在 stderr 输出人可读告警（或返回结构化失败记录），安全跳过故障扩展，不影响其余扩展的正常加载与主流程执行。
4. **测试与质量门禁**：
   - 单元测试 TDD 覆盖全部扫描、发现与加载函数（`tests/liii/pi/extension/discovery/` 与 `loader/`）；
   - 通过 `timeout 600 xmake b goldfish`、`bin/gf fmt`、`git diff --exit-code`、`bin/gf check`；
   - 提供 `tools/pi/devel/071.scm` 验收脚本，全部断言通过。

## 2026-10-20 任务描述

### What

1. 依据 `Agents.md` 任务 071 规格，建立 PLAN 任务文档 `tools/pi/devel/071.md`；
2. 梳理插件扫描与发现模型：分层路径（内置、全局、项目、命令行）、文件与子目录（`*.scm` 与 `*/index.scm`）匹配逻辑；
3. 规范插件加载协议与注入契约：设计 `load-extension` 与 `load-all-extensions`，将 `ExtensionAPI` 注入插件工厂；
4. 规划异常隔离机制与单元测试 fixtures，为开发阶段做好准备。

### Why

原生 pi 的强大之处在于“约定即发现”的轻量插件生态——开发者只需把扩展脚本放到全局或项目目录中，启动时即可自动生效。070 任务已完成了 ExtensionAPI 与生命周期底座，071 任务将打通从文件系统发现扩展并加载进 API 的完整通道，为后续工具解耦（072）、CLI 路由解耦（073）及内置扩展迁移（075）提供核心载入驱动力。

### How

1. **扫描发现（Discovery）**：
   - 使用 `(liii os)` 检查目录存在性与列出文件/目录；
   - 对单层目录中每个条目判断：若是以 `.scm` 结尾的常规文件则作为扩展入口；若是子目录且包含 `index.scm`，则以该 `index.scm` 作为扩展入口；
   - 分层扫描组合（内置 -> 全局 -> 项目 -> 命令行显式），利用路径规范化去重；
2. **插件契约与加载（Loader）**：
   - 在 S7 Scheme 中安全 load/eval 扩展文件；
   - 支持扩展返回工厂过程 `(lambda (api) ...)`，加载器传入当前运行期的 `api` 进行初始化；
   - 包裹 `catch` 异常防护网：无论是读文件失败、解析错误、还是工厂执行时抛错，均记录错误日志并跳过，确保主 Agent 进程永不崩溃。
3. **约束保持**：
   - 每个模块文件控制在 300 行以内；测试目录镜像源码库；遵循 Goldfish 命名规范与错误体系。
