## 验收点

- 对齐 pi 的 model-resolver 行为：
  - `--model <id>` 未命中当前 provider 时，在全部 provider 的模型目录（`models-store.json` 各 provider 条目 + 各 provider 内置模型）中搜索，命中即隐式选定 provider。
  - 用户显式指定 `--provider` 时以用户指定为准，或未命中时兜底当前 provider。
  - 仍未命中全部 provider 时，走自定义模型兜底（保持当前 provider + 告警提示）。
  - 处理多 provider 同名歧义策略（按已知优先级首个命中或明确处理）。
- 实测用例：
  - `bin/gf pi -p --model k3 "你是什么模型?"` 应自动路由到 kimi 并正常回答（当前报 404）。
- TDD 测试覆盖：
  - 命中特定 provider 模型（如 `k3` 自动路由 kimi，`gemini-2.5-flash` 路由 google，`glm-4-plus` 路由 glm，`deepseek-chat` 路由 deepseek 等）。
  - 未命中任何 provider 模型时的 fallback 行为与 warning。
  - 多 provider 同名或指定 provider 覆盖时的行为。
- 门禁检查全部通过：
  - `timeout 600 xmake b goldfish`
  - `timeout 120 bin/gf fmt`
  - `git diff --exit-code`
  - `timeout 120 bin/gf check`
  - `bin/gf doc --build-json`
