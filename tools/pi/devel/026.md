## 日期 任务描述

### 2026-10-19 任务建档

#### What

1. 查阅 `PI_PLAN.md` §3 任务 026 验收点与问题现场：
   - 现场复现：`timeout 180 bin/gf pi --mode json --tools bash "用 bash 工具运行命令 echo win-bash-ok"` 挂死至 120 秒超时并返回 `isError: true`。
   - 根因分析：`tools/pi/liii/pi/bash.scm` 硬编码 `(run-either (list "/bin/bash" "-c" command) ...)`，在 Windows 下无法正确定位 `/bin/bash`，且子进程 stdin/stdout 管道未妥善处理可能导致阻塞等待。
   - 方案分析：基于 `(os-type)` 做跨平台探测，在 Windows 环境下按优先级查找 Git Bash 路径（`C:\Program Files\Git\bin\bash.exe` 等）以 `bash -c <cmd>` 方式 spawn 并安全处理 IO 流。
2. 从 `tools/pi/devel/ddd.md` 模板建立 `tools/pi/devel/026.md`，明确状态、相关文件、验收点与测试方法。

#### Why

- `bin/gf pi` 的 bash 工具在 Windows（Git Bash 环境）无法运行，不仅导致用户在 Windows 上无法使用 bash 工具，也是 §5.5 pi 自举运行 git 命令的前置阻塞条件。

#### How

- 在 `tools/pi/liii/pi/bash.scm` 中增加平台探测与 Windows bash 路径解析逻辑。
- 确保测试用例覆盖跨平台 bash 命令构建与执行。
