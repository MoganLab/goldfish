# [080] 会话时限注入 system prompt：让 agent 感知剩余预算

> 5) 补齐 TDD 单元测试与端到端防回归覆盖。

## 验收点

1.0 **静态系统提示词注入预算约束说明**：
- `pi-build-system-prompt` 支持接收 `session-timeout` 与 `max-turns` 参数；
- 当指定有限正数时，生成结构化的 `<session_budget>` 节点（如总会话时限 N 秒、最大轮次 M 轮）；
- 当指定为 0（无限制）或 `#f` 时，如实标注无硬性超时或不限轮次，避免模型产生错误预期。

2.0 **回合级动态预算与进度可见性（Turn-level Visibility）**：
- 在 agent 多轮交互循环中，通过 `pi-resolve-turn-system-prompt` 或 turn 注入机制，向模型提供当前轮次与剩余时间概况（如当前第 N 轮，剩余约 T 秒）；
- 让 agent 能够实时自我衡量工作进度，合理规划每一步是深入探索还是收敛验证。

3.0 **临界预算警报与自动收敛引导（Budget Warning）**：
- 当剩余时间不足（如剩余时间 < 60 秒或 < 10%）或剩余轮次临近枯竭（如剩余 <= 3 轮）时，在系统提示词末尾注入醒目的 `<budget_warning>`；
- 引导 agent 停止执行耗时的新工具调用，优先将已有结果、关键结论与验收依据总结输出，杜绝进程因到达死线被硬性杀掉而丢失产出。

4.0 **CLI 与执行流程无缝串联**：
- `modes/flow.scm` 正确提取 CLI 解析得到的 `session-timeout` 与 `max-turns`（含缺省默认值 600s / 200 轮），并传递给 `pi-build-system-prompt` 与 `run-agent-loop`；
- 自举运行或手动执行（如 `--session-timeout 5400 --max-turns 0`）时，预算信息能准确无误地反映在模型的初始与动态提示词中。

## 2026-10-21 任务描述

### What

1.0 在 `tools/pi/liii/pi/prompt.scm` 中增加对 `session-timeout` 与 `max-turns` 预算配置的支持，构建 `<session_budget>` 章节；
2.0 在 `tools/pi/liii/pi/agent.scm` 中增强动态回合系统提示词解析能力，结合单调时钟计算剩余时间并监控轮次，注入当前预算状态及临界收敛预警；
3.0 在 `tools/pi/liii/pi/modes/flow.scm` 中打通参数传递链路；
4.0 编写充分的单元测试与 `tools/pi/devel/080.scm` 验收脚本。

### Why

- 在真实长任务与自举运行（如 070、074）中，agent 曾多次遭遇静默截断（`Session timeout exceeded` 或 `Maximum turns limit reached`）；
- 核心根因是提示词中没有任何时限与预算信息，agent 完全不知道硬性死线的存在，在耗尽前仍不断执行无关检索或单测，无法预留时间写出关键总结和验收报告；
- 让预算对 agent 可见是实现长任务稳健自举和自主配速的关键基础设施。

### How

- 在 `pi-build-system-prompt` 中新增可选关键字参数 `(session-timeout 600)` 和 `(max-turns 200)`；
- 格式化 `<session_budget>` 节点注入提示词；
- 在 `agent.scm` 的多轮循环中计算剩余单调秒与已消耗轮次，动态生成或追加预算提示。
