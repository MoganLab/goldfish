## 验收点

- 定位并解决 DeepSeek 模型目录解析问题：
  - 排查并支持 `~/.pi/agent/models.json` 及 `models-store.json` 中 deepseek 模型元数据的加载与解析。
  - 确保 `deepseek-v4-flash`、`deepseek-chat`、`deepseek-reasoner` 等模型可被正确识别与解析（含 contextWindow、maxTokens 等）。
  - `bin/gf pi --provider deepseek --list-models` 能正确列出 deepseek 系列模型。
- DeepSeek Provider 端点与协议适配：
  - 凭据解析：优先复用 auth.json / models.json 或环境变量 `DEEPSEEK_API_KEY`。
  - 端点路由：接入 `https://api.deepseek.com/anthropic`（或 OpenAI Completions 兼容路径）。
  - 请求构造与流式/非流式响应解析：正确处理 tool_use、thinking、stop_reason 与 usage 映射。
- 真实冒烟验证：
  - 纯文本对话：`timeout 120 bin/gf pi --provider deepseek --model deepseek-v4-flash -p "..."` 成功返回并退出码 0。
  - 管道与工具调用：`git diff | timeout 180 bin/gf pi --provider deepseek --model deepseek-v4-flash --tools bash -p "..."` 正确执行工具并总结输出。
- TDD 单测覆盖：
