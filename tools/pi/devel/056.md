> **任务**：`(liii tui keys)` 键盘输入与转义序列解析
> **内容与验收点**：纯函数解析终端输入字符串/字节流，映射为标准按键符号（`'up`、`'down`、`'left`、`'right`、`'enter`、`'backspace`、`'tab`、`'ctrl-c`、`'ctrl-d`、字符文本等）；单函数单测试，全量覆盖 ANSI/xterm 转义序列。

### 架构约定与设计原则

1. **纯函数无副作用**：
   - `keys` 模块不直接读取标准输入（stdin），不依赖真实 TTY 环境；
   - 输入为普通字符串或字符流，输出为标准按键事件列表或单个按键对象；
   - 保证 100% 确定性，方便单元测试与全流程无头录制/回放测试。
2. **标准按键映射规范**：
   - 方向键：`'up`、`'down`、`'left`、`'right`（支持 ANSI `\x1b[A`..`D` 与 xterm/SS3 `\x1bOA`..`D`）；
   - 基础控制键：
     - 回车：`'enter`（`\r`、`\n`）；
     - 制表符：`'tab`（`\t`）；
     - 退格：`'backspace`（ASCII BS `\x08`、DEL `\x7f`）；
     - ESC：`'escape`（孤立 `\x1b`）；
     - 控制组合键：`'ctrl-a` 至 `'ctrl-z`（ASCII 1~26，特别覆盖 `'ctrl-c`、`'ctrl-d`、`'ctrl-z` 等）；
   - 编辑与导航键：
     - `'home`、`'end`（`\x1b[H`、`\x1b[F`、`\x1b[1~`、`\x1b[4~`、`\x1bOH`、`\x1bOF`）；
     - `'page-up`、`'page-down`（`\x1b[5~`、`\x1b[6~`）；
     - `'insert`、`'delete`（`\x1b[2~`、`\x1b[3~`）；
   - 功能键（F1 - F12）：
     - F1 至 F4（`\x1bOP`..`\x1bOS`、`\x1b[[A`..`\x1b[[E`）；
     - F5 至 F12（`\x1b[15~`、`\x1b[17~`..`\x1b[21~`、`\x1b[23~`、`\x1b[24~`）；
   - 修饰键组合（Shift/Alt/Ctrl 导航组合）：
     - 解析 xterm CSI 参数序列（如 `\x1b[1;5A` 代表 Ctrl+Up，`\x1b[1;2B` 代表 Shift+Down）；
     - 产出清晰可区分的键值表示（如 `'(ctrl up)` 或 `'ctrl-up`）；
   - 普通字符与文本：
     - 普通可见 ASCII 字符（如 `'a'`、`'1'`、`' '`）与多字节 UTF-8 字符（如中文汉字、全角标点、Emoji 等）作为字符或文本事件返回。
3. **流式与多按键解析**：
   - 提供 `parse-key` 解析单个按键（支持返回消耗长度或剩余字符串）；
   - 提供 `parse-keys` 将输入字符串完整解析为按键列表，正确切分连击或粘连的按键序列；
   - 对于未知或不完整的转义序列，进行安全回退，绝不崩溃死循环。
4. **单文件 300 行与拆分规范**：
   - 严格遵循 `bin/gf check` 的单文件 <= 300 行约束；
   - 逻辑清晰拆分到子模块，保持模块小巧紧凑；
   - 单函数单测试，镜像测试目录结构。

## 验收点

1. **基本字符与回车退格控制键**：
   - ASCII 普通可见字符（英文字母、数字、符号、空格）正确解析；
   - 多字节 UTF-8 字符（中文汉字、全角符号、Emoji）正确解析；
   - 回车键（`\r`、`\n`、`\r\n`）解析为 `'enter`；
   - 制表符（`\t`）解析为 `'tab`；
   - 退格键（`\x08`、`\x7f`）解析为 `'backspace`；
   - 孤立 ESC（`\x1b`）解析为 `'escape`。
2. **Ctrl 控制键**：
   - `\x01` 解析为 `'ctrl-a`；
   - `\x03` 解析为 `'ctrl-c`；
   - `\x04` 解析为 `'ctrl-d`；
   - 完整支持 Ctrl+A 到 Ctrl+Z 的标准映射。
3. **ANSI / VT100 / xterm 方向键与导航键**：
   - `\x1b[A` 与 `\x1bOA` 解析为 `'up`；
   - `\x1b[B` 与 `\x1bOB` 解析为 `'down`；
   - `\x1b[C` 与 `\x1bOC` 解析为 `'right`；
   - `\x1b[D` 与 `\x1bOD` 解析为 `'left`；
   - Home / End 键（`\x1b[H`、`\x1b[F`、`\x1b[1~`、`\x1b[4~`、`\x1bOH`、`\x1bOF`）解析为 `'home`、`'end`；
   - PageUp / PageDown（`\x1b[5~`、`\x1b[6~`）解析为 `'page-up`、`'page-down`；
   - Insert / Delete（`\x1b[2~`、`\x1b[3~`）解析为 `'insert`、`'delete`。
4. **功能键与修饰键序列**：
   - F1 到 F12 标准转义序列映射（如 `\x1bOP`..`\x1bOS`、`\x1b[15~` 等）；
   - 带修饰键的扩展序列（如 `\x1b[1;5A` Ctrl+Up 等）正确识别。
5. **按键流连续解析 (`parse-keys`)**：
   - 多个连续按键连击输入时（如 `"abc\x1b[A\r"`），能完整按顺序解析为对应按键列表；
   - 混合普通字符与转义序列不出错、不丢字符；
   - 空字符串返回空列表 `'()`；
   - 未知转义字符安全容错。
6. **边界与单测覆盖**：
   - 单函数单测试，测试覆盖所有上述键位与边界；
   - 全程不依赖真实 TTY，支持确定性脱机执行。
7. **门禁与代码规范**：
   - `timeout 600 xmake b goldfish` 构建通过；
   - `timeout 120 bin/gf fmt` 格式化通过无 diff；
   - `git diff --exit-code` 保证工作区整洁；
   - `timeout 120 bin/gf check` 静态检查（单文件 <= 300 行）全绿；
   - `timeout 120 bin/gf doc --build-json` 成功更新函数索引。

#### How
- 遵循 TDD 流程，先编写测试用例覆盖全部键位与转义组合；
- 使用 `bytevector-advance-utf8` 精准支持多字节 UTF-8 字符；
- 控制函数粒度与调用栈深度，保证 AST 最大嵌套深度 <= 15；
- 单文件行数均在 200 行以内，远低于 300 行上限。
