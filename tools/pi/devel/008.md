## 验收点

- 凭据与配置发现：
  - 凭据优先从 `~/.pi/agent/auth.json` 消费 `kimi-coding`（type: "api_key"）。
  - 若 `auth.json` 未配置，支持通过环境变量 `KIMI_API_KEY` 兜底。
  - 默认端点为 `https://api.kimi.com/coding/v1`（OpenAI Chat Completions 协议），支持 `models-store.json` 与 `GF_PI_BASE_URL` 覆盖。
  - 默认模型为 `kimi-for-coding`。
  - 凭据缺失时明确报错（退出码 1，错误信息清晰可读，不静默挂起）。
- 非流式与 function calling：
  - 正确构造 OpenAI Chat Completions 格式请求（含 messages、tools、tool_choice 等）。
  - 鉴权头带 `Authorization: Bearer <key>`。
  - 响应解析正确映射 finish_reason（stop、tool_calls 等）、content 文本及 tool_calls。
  - 正确处理多轮对话与工具执行结果回传。
- 流式 SSE 支持：
  - 支持 SSE 流式传输（`stream: true`），解析 delta 文本与 delta tool_calls。
  - 准确派发 `message_update` / `tool_execution_update` / `message_end` 等事件。
  - 具备流式空闲超时兜底，杜绝静默挂起。
- 错误路径处理：
  - 401（未授权/无效 key）、404（模型不存在）、429（限流/配额耗尽）、5xx（服务端错误）能被结构化捕获并输出人可读的错误诊断摘要。
- 自动化测试与验证：
  - 完整的 stub 单元测试覆盖各核心功能与异常分支。
  - 真实网络冒烟验证通过（纯文本 print 模式与 bash 工具往返执行）。
- 门禁检查全部通过：
  - `timeout 600 xmake b goldfish`
  - `timeout 120 bin/gf fmt`
  - `git diff --exit-code`
  - `timeout 120 bin/gf check`
