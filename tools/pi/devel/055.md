### 架构约定与设计原则

1. **纯函数无副作用**：`text-width` 工具集全部为纯函数，不依赖真实终端，纯内存字符串计算，保证 100% 确定性与高可测性。
2. **ANSI 安全性**：
   - 终端转义序列（以 ESC `\x1b` 起始的 CSI/SGR 控制码，如 `\x1b[31m`、`\x1b[0m`）显示宽度必须计为 0；
   - 截断（truncate）和折行（wrap）绝不能在转义序列中间切断导致终端乱码；
   - 被截断或跨行时妥善处理样式状态（截断尾部重置 `\x1b[0m`，防止样式泄漏污染后续行）。
3. **Unicode 列宽正确性**：
   - ASCII 可见字符占 1 列；
   - CJK 表意文字、全角符号、常见 Emoji（如 `😊`、`🚀` 等）占 2 列；
   - 零宽字符（Zero-width joiner、组合修饰字符 Combining Marks）占 0 列；
   - CJK 双宽字符在行尾不能被劈半（若剩余宽度为 1 则必须提前换行或截断）。
4. **单文件 300 行与拆分规范**：
   - 纯函数逻辑紧凑严谨，单文件严格控制在 300 行以内；
   - 单函数单测试，镜像测试目录结构，覆盖完整边界用例。

## 验收点

1. **`strip-ansi` 纯函数**：
   - 正确剔除字符串中的 ANSI SGR 颜色码及 CSI 序列（如 `\x1b[31;1m`、`\x1b[0m`）；
   - 普通纯文本原样返回；
   - 空字符串安全返回空字符串。
2. **`display-width` 纯函数**：
   - ANSI SGR/CSI 转义序列宽度为 0；
   - ASCII 可见字符宽度为 1；
   - CJK 汉字、全角标点符号宽度为 2；
   - 常见 Emoji 字符（宽字符区）宽度为 2；
   - 组合字符（Combining Marks）及零宽字符宽度为 0；
   - 包含多类字符混合及 ANSI 彩色样式的字符串返回精确视觉显示宽度。
3. **`truncate-to-width` 纯函数**：
   - 按指定的视觉显示宽度（列宽）截断单行文本；
   - 超出部分默认附加省略号 `...`（占用 3 列，可自定义省略符）；
   - 绝不切断 ANSI 转义序列；若文本带有样式且被截断，在尾部自动补充 `\x1b[0m` 避免终端样式溢出污染；
   - 绝不劈裂 CJK 双宽字符（若剩余宽度仅剩 1 列且遇双宽字符，提前截断）；
   - 极小宽度（如 `<= 3`）、零宽度、负宽度与空字符串安全处理。
4. **`wrap-text` 纯函数**：
   - 按指定视觉显示宽度对长文本自动折行，返回行字符串列表；
   - 支持原文本内含 `\n` 换行符的独立分段换行；
   - 折行时不破坏 ANSI 序列，双宽字符不超宽折行；
   - 英文优先空格断词折行，无空格超长字符或 CJK 文本按列宽硬折行。
5. **054 组件迁移**：
   - `make-text` 组件迁移至 `wrap-text` 实现，天然具备中文 CJK 与 ANSI 彩色折行能力；
   - `make-truncated-text` 组件迁移至 `truncate-to-width` 实现，具备准确显示宽度截断与 ANSI 安全保护；
   - 054 所有已有单测保持 100% 绿灯。
6. **边界与单测覆盖**：
   - 单函数单测试，覆盖 ASCII/CJK/emoji/ANSI/零宽/负宽/正好等宽边界；

3. 规划 ASCII、CJK 全角、Emoji、ANSI CSI/SGR 序列及零宽字符的宽度计算与安全截断折行规则；

5. 冻结验收点、测试命令序列与文件规划；
6. 提交 PLAN 阶段 commit。

### Why

终端用户界面中，中文字符（2 列）与 ANSI 颜色控制码（0 列）如果按字节或字符数量简单截断折行，会导致界面排版严重错乱、双宽字符被切碎或终端颜色泄露。必须在布局组件之前提供健壮高效的显示宽度与 ANSI 感知纯函数文本工具。

### How

1. `strip-ansi`：状态机或正则/字符流扫描，匹配 `ESC [` 到终止字符（`0x40`-`0x7e`，如 `m`、`H` 等）并剔除；
2. `display-width`：扫描字符串字符（支持 UTF-8 Unicode 码点），跳过 ANSI 序列，根据 Unicode 码点范围判定字符宽度（CJK、全角标点、Emoji 返回 2；组合标音符号返回 0；标准 ASCII 返回 1）；
3. `truncate-to-width`：按列宽累加，遇到 ANSI 序列完整保留不计列宽，超出时追加省略符并在行尾自动闭合 `\x1b[0m`；
4. `wrap-text`：按行宽贪心组装，遇到空白符断词折行，遇到中文字符在到达行宽上限时自动换行，折行不截断 ANSI 序列。
