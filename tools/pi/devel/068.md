# [068] Linux 平台终端原始模式与按键适配

> 本文件是任务 068 的任务文档，从 `tools/pi/devel/ddd.md` 模板建立。

## 任务背景与目标

在此前任务 054~067 中，`(liii tui)` 交互终端和贪吃蛇示例主要在 Windows 开发机环境下调试。底层按键依赖 Windows 的 `<conio.h>`（`_kbhit` 与 `_getch`），在 Linux/macOS 平台下存在以下关键缺失：
1. **胶水层缺失**：`src/liii_os.cpp` 中 `g_console_kbhit` 与 `g_console_getch` 在非 Windows 平台直接硬编码返回 `#f`；
2. **规范模式阻断**：Linux/POSIX 终端默认处于 Canonical 规范模式（带回显且需要按回车才将输入行送入输入缓冲），无法感知实时单键敲击；
3. **按键编码差异**：Windows 下方向键等特殊按键通过 `0` 或 `224` 引导扩展码，而 Linux 终端发送的是标准 ANSI 转义序列（如 `\x1b[A` 代表向上）；若不进行流式拼接与解析，读到 `\x1b` 会被误判为独立的 `escape`。

本任务目标：
- 在 POSIX 平台实现标准的 `termios` 原始模式（Raw Mode）管理与退出安全恢复机制；
- 实现 POSIX 下基于 `poll` 的非阻塞按键检测（支持毫秒级超时等待）与非阻塞单字节读取；
- 在 `(liii tui terminal poll)` 中接入 ANSI 转义序列解析，支持方向键与各类功能键无缝映射；
- 在 `demo/tui/snake.scm` 中引入 `dynamic-wind` 终端生命周期保护；
- 实测 Linux 终端键盘响应正确，全量单测通过。

## 架构与核心实现

### 1. POSIX 终端 Raw 模式与生命周期安全 (`src/liii_os.cpp`)

- **termios 配置**：
  引入 `<termios.h>`，实现 `g_console_raw_mode(bool enable)`：
  - `enable == true`：
    - 检查 `isatty(STDIN_FILENO)`，若非终端设备则安全返回 `#f`；
    - 使用 `tcgetattr(STDIN_FILENO, &g_orig_termios)` 留存终端原始配置；
    - 通过 `atexit(restore_terminal_mode_at_exit)` 注册进程退出时的自动恢复回调，防止异常退出导致终端卡死在无回显状态；
    - 修改标志位：关闭 `ICANON`（禁用行缓冲缓冲）、关闭 `ECHO`（禁用自动回显），设置 `VMIN = 0, VTIME = 0`；
    - 使用 `tcsetattr(STDIN_FILENO, TCSANOW, &raw)` 立即生效；
  - `enable == false`：恢复原始 `g_orig_termios` 配置。
  - Windows 平台下该函数为空操作并安全返回 `#t`。

### 2. 非阻塞检测与毫秒超时机制 (`f_console_kbhit`)

- 支持可选参数 `timeout_ms`（默认 0 为完全非阻塞）：
  - **POSIX 平台**：使用 `<poll.h>` 对 `STDIN_FILENO` 的 `POLLIN` 事件进行监听：
    ```cpp
    struct pollfd pfd = { STDIN_FILENO, POLLIN, 0 };
    int ret = poll(&pfd, 1, timeout_ms);
    return s7_make_boolean(sc, ret > 0 && (pfd.revents & POLLIN));
    ```
    非 TTY 设备时直接安全返回 `#f`，避免重定向或 EOF 时误判。
  - **Windows 平台**：若 `timeout_ms > 0` 且 `_kbhit()` 未命中，使用小粒度 `Sleep(1)` 循环轮询直至超时，双端行为一致。

### 3. 非阻塞按键读取 (`f_console_getch`)

- POSIX 平台下从 `STDIN_FILENO` 非阻塞读取 1 字节：
  - 成功读取返回整数 ASCII 码（0~255）；
  - 无输入或 EOF 时安全返回 `#f`（不阻塞、不抛异常）。

### 4. ANSI 转义序列流式收集与解析 (`(liii tui terminal poll)`)

- 在 `goldfish/liii/tui/terminal/poll.scm` 中：
  - 读取到字节 `27`（ESC）时，调用 `%poll-escape-key`：
    - 首先等待最多 25ms（`console-kbhit? 25`）探测后续字节；
    - 若超时无后续字节，精确判定为独立的 `'escape` 键；
    - 若有后续字节，则持续流式收集连续转义字符序列；
    - 传入纯函数 `%resolve-ansi-bytes`，通过 `(liii tui keys parser)` 中的 `parse-key` 将 ANSI 序列自动解析为标准符号（`'up`、`'down`、`'left`、`'right`、`'home`、`'end`、`'delete`、`'page-up`、`'page-down`、`'f1` 等）；
  - 修正了 Windows 扩展键与 ANSI 解析间关于 `'page-up` / `'page-down` 的符号命名一致性。

### 5. 贪吃蛇生命周期保护 (`demo/tui/snake.scm`)

- 主运行逻辑用 `dynamic-wind` 全流程包裹：
  - `before`: 开启 `(console-raw-mode! #t)`，隐藏光标并清屏；
  - `thunk`: 执行贪吃蛇主循环与尺寸自适应；
  - `after`: 必定恢复 `(terminal-show-cursor! term)` 与 `(console-raw-mode! #f)`，彻底防止用户退出游戏后终端回显丢失。
