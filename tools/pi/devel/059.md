### 架构约定与设计原则

1. **组件协议对齐**：
   - 动态加载转轮组件（`make-spinner`）与状态指示组件（`make-status-indicator`）均实现标准的 `<component>` 协议（来自 `(liii tui component)`）；
   - `component-render` 接受给定的总渲染宽度 `width`，返回渲染后的行文本列表 `(list of string)`；在隐藏状态下返回空列表 `'()`；
   - 交互输入下发 `component-handle-input`：转轮组件本身通常不拦截交互事件，默认返回 `#f`，保持事件透传；
   - 状态失效通知 `component-invalidate!`：清除组件缓存，标记需要重新渲染。

2. **内置转轮帧与自定义帧序列**：
   - 提供丰富的开箱即用内置转轮帧（内置于 `(liii tui loader frames)`）：
     - `'dots`：Braille 点阵转轮（`⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏`）
     - `'line`：经典 ASCII 转轮（`| / - \`）
     - `'arrows`：八向箭头转轮（`← ↖ ↑ ↗ → ↘ ↓ ↙`）
     - `'pulse`：脉冲条形转轮（`█ ▓ ▒ ░ ▒ ▓`）
     - `'simple-dots`：简单三点转轮（`.  .. ...`）
   - 支持通过列表或向量传入完全自定义的帧字符序列。

3. **状态推进与帧管理（Tick）**：
   - `spinner-tick!`：单步推进转轮到下一帧，支持自动环状循环；
   - 提供获取与设置当前帧索引接口（`spinner-frame-index`、`spinner-frame-index-set!`、`spinner-reset!`）；
   - 支持总帧数查询 `spinner-frame-count` 与当前帧字符提取 `spinner-current-frame`。

4. **前缀与后缀文本提示**：
   - 支持通过关键字参数初始化：`:prefix`（前缀文本，位于转轮左侧）、`:suffix`（或 `:message`，后缀说明文本，位于转轮右侧）；
   - 运行时动态更新文本：提供 `spinner-set-prefix!`、`spinner-set-suffix!`、`spinner-set-message!`，更新后自动调用 `component-invalidate!`。

5. **显示与隐藏切换（Visibility）**：
   - 支持 `:visible?` 初始化开关（默认 `#t`）；
   - 提供 `spinner-visible?` 查询与 `spinner-show!`、`spinner-hide!`、`spinner-set-visible!` 控制接口；
   - 隐藏状态下，`component-render` 返回 `'()`（0 行），不占用任何垂直屏幕空间。

6. **状态指示组件扩展（`make-status-indicator`）**：
   - 在 CLI/TUI 工具中，加载状态常常需要在任务完成后无缝切换为“成功”、“失败”或“警告”状态；
   - 提供状态指示组件，支持多种预设状态：
     - `'loading` / `'spinning`：展示动态转轮与进行中提示；
     - `'success`：展示绿色/勾选标识（如 `✔` 或 `[OK]`）与成功文本；
     - `'error` / `'failure`：展示红色/叉号标识（如 `✖` 或 `[ERR]`）与错误文本；
     - `'warning`：展示黄色/叹号标识（如 `⚠` 或 `[WARN]`）与警告文本；
     - `'idle` / `'info`：展示中立提示符号与信息；
   - 支持动态切换状态（`status-indicator-set-status!`），兼具动画转轮与固定状态展示。

7. **文本宽度自适应与截断保护**：
   - 渲染行长度利用 `(liii tui text-width)` 的 `truncate-to-width` 与 `display-width` 校验，当指定 `width` 小于转轮及文本总宽时，优雅截断并追加省略号，确保不溢出终端边界。

8. **单文件 300 行与模块拆分规范**：
   - 严格遵循 `bin/gf check` 的单文件 <= 300 行硬约束；
   - 模块划分为：
     - `(liii tui loader frames)`：转轮帧常量定义与帧集合查找
     - `(liii tui loader spinner)`：`make-spinner` 核心动画转轮组件
     - `(liii tui loader status)`：`make-status-indicator` 状态指示器组件
     - `(liii tui loader)`：统一门面导出
     - `(liii tui)`：顶级门面再导出
   - 测试按 goldfish 规范单函数单测试，镜像源码库结构。

## 验收点

1. **转轮预设帧集合**：支持 `'dots`、`'line`、`'arrows`、`'pulse` 等内置帧，支持完全自定义帧序列，提供纯函数获取帧列表与总帧数；
2. **Component 协议合规**：`make-spinner` 与 `make-status-indicator` 完整实现 `<component>` 协议（render / handle-input / invalidate）；
3. **多帧状态推进**：`spinner-tick!` 能够正确循环递进帧状态，测试覆盖从第 0 帧到第 N-1 帧再回环至第 0 帧的完整周期断言；
4. **前后缀文本渲染**：支持指定 `:prefix` 和 `:suffix`（或 `:message`），支持运行时动态修改并使渲染结果即时生效；
5. **显示与隐藏控制**：支持 `:visible?` 参数及 `spinner-show!` / `spinner-hide!` 控制，隐藏时渲染行列表必须为空 `'()`；
6. **状态指示器状态切换**：`make-status-indicator` 支持 `'loading`、`'success`、`'error`、`'warning` 等状态切换与渲染断言；
7. **显示宽度保护**：当容器 `width` 不足时，转轮文本正确截断，不产生溢出换行；
8. **代码规范门禁**：所有新建及修改的代码单文件不超过 300 行，通过 `bin/gf check`；
9. **单元测试与文档索引**：单函数单测试，全量断言通过，`bin/gf doc --build-json` 正常无报错；
10. **端到端验收脚本**：`tools/pi/devel/059.scm` 独立执行通过，且所有前序测试不产生回归。
