## 日期 任务描述

### What

1. 从模板建立任务文档 `tools/pi/devel/007.md`（[007][PLAN] 阶段）。
2. 先为工具声明（tool definition）、工具执行结果（tool result）以及截断产物（truncation result）编写 `define-record-type` 谓词与访问器单测（TDD）。
3. 在 `tools/pi/liii/pi/tools.scm` 与 `tools/pi/liii/pi/truncate.scm` 中定义对应的 record 类型，实现构造器、谓词、字段访问器，并保持对已有代码的兼容。
4. 在门面库 `tools/pi/liii/pi.scm` 导出新类型与访问器。
5. 验证既有工具测试与 CLI 端到端行为零回归。
6. 编写并运行 `tools/pi/devel/007.scm` 验收脚本。

### Why

工具声明与工具执行结果是 Agent 调度和 Function Calling 交互的核心数据结构，截断产物是工具大输出安全控制的关键结构。原先使用 alist 表示容易产生键名混淆且类型检查弱。改用 Scheme R7RS 标准 `define-record-type` 后，提供强类型谓词与标准访问器，提升鲁棒性与可读性。

### How

使用 `define-record-type` 定义 tool-definition、tool-result、trunc-result 结构，提供构造器、谓词与字段访问器，并提供 record 转换为 alist 或支持 assoc 访问的兼容层，确保 Agent 调度层、Provider 映射层无缝过渡。
