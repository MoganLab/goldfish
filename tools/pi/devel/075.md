5. 编写验收脚本 `tools/pi/devel/075.scm`，完成 REVIEW 阶段验收并推送到远程分支，使 CI 恢复全绿。

### Why

CI 环境与本地开发环境的差异在于：CI 环境为全新纯净容器，既没有注入真实 API Key 环境变量，也没有 `~/.pi/agent/auth.json` 凭据文件。
`dispatch-pi` 依据设计，在进入 custom session flow（非 local flow）之前会强制检查是否存在有效凭据；原测试用例未传递 `--api-key`，导致在 CI 环境下触发 `credential-error ("No credentials found for provider \"google\"")`，阻塞了 CI 流水线。

### How

在测试用例中传递显式 `--api-key dummy-key`，使 `resolve-pi-config` 生成包含 api-key 的配置，满足凭据检查门禁，同时保持测试关注点（即自定义 session flow 的注册与动态调度执行）不受影响。
