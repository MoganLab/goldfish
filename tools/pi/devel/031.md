## 验收点

- CLI 参数解析支持：
  - 支持 `--session-timeout <秒>` 参数，解析为数值存入 `(cons 'session-timeout <秒>)`。
  - 未指定时为 `#f`，默认由 `modes.scm` / `agent.scm` 提供缺省 600 秒兜底。
  - 支持传入 0，表示关闭会话级超时兜底（运行不设 deadline 限制）。
- 会话级超时生效机制：
  - 当 `session-timeout > 0` 时，若整个会话运行耗时超过该秒数，结构化返回包含 `"Session timeout exceeded"` 的错误 assistant message，并触发完整的 `agent_end` 与 `agent_settled` 事件，退出码为 1。
  - 当 `session-timeout` 为 0 时，关闭超时兜底，不因会话耗时截断多轮循环。
  - 负数或立即超时的边缘情况（负数仍可视为立即超时用于单测，但 0 专用于关闭兜底）。
- 串联与优先级：
  - CLI 选项 `--session-timeout` 优先级高于配置中的默认值。
  - 运行时正确将解析出的 `session-timeout` 传递至 `run-agent-loop`。
- 帮助文本与文档：
  - `bin/gf pi --help` 包含 `--session-timeout <seconds>` 说明（标注 0 为关闭兜底，默认 600）。
  - `PI_SPEC.md` 包含该选项的用法说明。
- 门禁检查与测试全绿：
  - `timeout 600 xmake b goldfish`
  - `timeout 120 bin/gf fmt`
  - `git diff --exit-code`
  - `timeout 120 bin/gf check`
  - `bin/gf doc --build-json`
  - 既有单元测试与相关新增测试全绿。

### 2026-10-19 任务建档

#### What

1. 查阅 `PI_PLAN.md` §3 任务 031（差距清单 #8）的验收点与背景说明。
2. 从 `tools/pi/devel/ddd.md` 模板复制建立 `tools/pi/devel/031.md` 任务文档。
3. 明确任务涉及的代码文件、验收点（CLI 参数解析、0 关闭兜底、串联与生效、帮助信息更新）、测试方案及门禁流程。

#### Why

- 当前会话级超时兜底硬编码默认 600s，且无法通过 CLI 选项放宽或关闭（`--timeout` 仅管 bash/HTTP 单次超时）。
- 任务 025 自举开发等大任务运行时间超出 600s 时会被打断，阻塞大任务自举。
- 新增 `--session-timeout <秒>`（0 关闭兜底），便于在大任务执行时显式放宽超时限制（如 `--session-timeout 7000` 或 `--session-timeout 0`）。

#### How

- 在 `tools/pi/liii/pi/args.scm` 中增加 `--session-timeout <seconds>` 参数解析分支。
- 在 `tools/pi/liii/pi/agent.scm` 中调整 `session-timeout` 判断逻辑：当 `(= session-timeout 0)` 时不设 deadline 且不判定超时；仅当 `(> session-timeout 0)` 时计算 deadline，或负数 `< 0` 判定为立即超时。
- 在 `tools/pi/liii/pi/help.scm` 与 `PI_SPEC.md` 中增加 `--session-timeout <seconds>` 的使用说明。
- 编写单测覆盖参数解析（含 0 和正数）以及 agent 循环中 0 关闭兜底行为。
