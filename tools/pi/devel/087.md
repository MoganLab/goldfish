## 验收点

1.0 **Thinking 折叠卡片状态机设计（Thinking Card State）**：
- 定义 Thinking 卡片数据结构，包含 `content`（思维链内容）、`token-count`（Token 计数）、`collapsed?`（默认 `#t` 折叠态）、`completed?`（推理是否结束）以及 `scroll-offset`（展开态独立内部滚动偏移）；
- 提供纯函数式及受控更新接口（如 `make-thinking-card`、`thinking-card-toggle!`、`thinking-card-append-content!`、`thinking-card-set-completed!`）；
- 类型非法或缺少必填字段时按 Goldfish 规范抛出 `type-error`。

2.0 **折叠态单行紧凑摘要渲染（Collapsed Summary Rendering）**：
- 折叠态下紧凑展示为单行浅灰/暗色前缀摘要，不占用主消息视口过多垂直空间；
- 思考进行中展示如 `> [Thinking] 正在深度思考 (N tokens)...`；
- 思考完成后展示如 `> [Thinking] 推理已完成 (按 Tab 展开)`；
- 摘要输出正确适配终端宽度，超宽时优雅截断或省略。

3.0 **展开态 Box 边框包裹与内部独立视口排版（Expanded Viewport & Box Border）**：
- 展开态下通过单线 Box 边框包裹完整的思维链内容，与正文消息形成视觉层次区隔；
- 支持内部独立视口排版与折行（结合 `wrap-text`），当思维链过长时在固定最大高度内支持内部滚动浏览；
- 保证展开态在全屏差分渲染时不会溢出主视口分配的高度。

4.0 **快捷键调度与折叠状态切换（Key Binding & Toggle Dispatch）**：
- 支持 `Tab` 或 `Ctrl+O`（`'ctrl-o` / `"\x0f"`）快捷键平滑切换当前活跃或选中的 Thinking 卡片折叠/展开状态；
- 折叠状态变更时置脏状态标记（`state-dirty!`），无缝触发主事件循环局部差分重绘；
- 快捷键在输入框为空或非输入编辑热键冲突状态下正确生效。

5.0 **TDD 单元测试覆盖与门禁验证**：
- 为 Thinking 卡片创建、折叠摘要格式化、展开态排版、快捷键切换等逻辑编写完整单测；
- 门禁四连：`timeout 600 xmake b goldfish`、`timeout 120 bin/gf fmt`、`git diff --exit-code`、`timeout 120 bin/gf check`；
- 全量测试（包括 `bin/gf test tools/pi/tests/liii/...`）100% 通过无回归。

## 2026-10-21 任务描述

### What

1. 依据 `Agents.md` §3 任务 087 验收点从模板建立任务文档 `tools/pi/devel/087.md`；
2. 设计并定义 Thinking 推理思考过程的折叠卡片组件结构；
3. 规划折叠态单行摘要渲染与展开态 Box 边框内部排版方案；
4. 设计快捷键（Tab / Ctrl+O）在主事件循环与按键分发中的调度机制；
5. 准备 TDD 单元测试与验收脚本规范。

### Why

具备推理能力（Reasoning / Thinking）的大语言模型在生成最终答案前通常会产生长篇幅的思维链（Chain of Thought）。直接将上千字的思考过程与正文消息平铺不仅会大量冲刷历史对话屏幕，还会降低用户的阅读效率。设计动态折叠卡片组件，默认以紧凑单行摘要呈现思考进展与状态，用户按需（Tab / Ctrl+O）展开独立视口查看深度推演细节，是现代化终端 Agent 交互的关键体验。

### How

- 定义 `pi-tui-thinking-card` 记录类型，封装思考文本、Token 计数、折叠状态、完成状态与滚动偏移；
- 折叠渲染函数 `render-thinking-collapsed` 根据状态输出单行摘要 `> [Thinking] 正在深度思考 (N tokens)...` 或 `> [Thinking] 推理已完成 (按 Tab 展开)`；
- 展开渲染函数 `render-thinking-expanded` 结合 `(liii tui text-width)` 对思考文本进行排版，通过字符边框包裹，并支持内部视口按行截取展示；
- 在按键分发 `dispatch.scm` 中响应 `tab` 与 `ctrl-o` 事件，切换活跃 Thinking 卡片的 `collapsed?` 并将状态标记为脏，触发差分渲染引擎刷新。
