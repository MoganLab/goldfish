### Why
fold 是最基础的列表迭代器，mogan kernel 的 list-fold / list-fold-right
（27 处调用，且 list-intersperse、string-split-lines 等内部也经由此路）
可直接落到原生实现。fold-right 的 Scheme 单列表路径是非尾递归，
深度受 Scheme 栈限制，C 化同时消除这个限制。

### How
- 沿用 [0098] g_any 的 GC 模式：args 可能住在求值器复用的临时 cell 里，
  anchor 保存 f / lst；acc 放在 anchor 挂着的专用 cell 里，每轮
  s7_apply_function 后立即写回，保证中间累加值对 GC 可见
- f 按 SRFI-1 签名 `(f elem acc)` 经 s7i_set_plist_2 调用
- fold-right 先把元素复制成逆序列表（挂在 anchor 上），再正向遍历执行
  acc = f(elem, acc)——等价于右结合展开，且把 Scheme 栈递归换成 O(n) 堆分配
- 空列表直接返回 initial，不构造 anchor

### 方案讨论：多列表分支（已定稿）
- 多列表 fold 每步要 map car/cdr + apply，mogan 侧用法也以单列表为主，
  C 化收益低、复杂度高，保持原 Scheme 实现
