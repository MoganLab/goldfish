## 2026-09-08 修复 tools/doc 缺少索引提示测试的环境隔离与索引文件跟踪

### What
1. 取消误被 git 跟踪的 `tools/doc/tests/function-library-index.json`，使其遵循 `.gitignore` 规则并从工作区移除。
2. 重构 `tools/doc/tests/liii/golddoc/missing-index-hint-test.scm`：
   - 动态通过 `find-function-index-paths` 及项目根目录、子模块路径收集所有可能存在的函数索引文件；
   - 在测试运行前备份并临时清理所有现有索引文件，并在 `dynamic-wind` 清理中保证完整恢复；
   - 修复在无论是否存在已构建主索引文件的开发机与 CI 环境下均能稳定触发缺索引提示。
3. 确保测试用例在项目根目录运行和在 `tools/doc` 目录下运行均能正确通过。

### Why
1. `bin/gf test tools/doc/tests` 会自动切换工作目录到 `tools/doc`。如果只处理相对路径 `tests/function-library-index.json`，开发机上主根目录已存在的索引文件不会被清理，子进程 `gf doc` 通过 load-path 仍能检索到函数文档，未能触发“缺少索引时给出 hint”的错误分支，导致断言失败退出（exit code 255）。
2. `tools/doc/tests/function-library-index.json` 属于构建派生产物且已声明在 `.gitignore` 中，不应被提交进版本控制。

### How
1. 使用 `(find-function-index-paths)` 以及通过 `(executable)` 相对推导的根目录路径，收集所有存在的 `function-library-index.json` 路径并去重。
2. 使用 `dynamic-wind` 确保执行前临时删除索引文件，执行后将保存的索引内容完整写回，保证测试环境隔离和无副作用。
