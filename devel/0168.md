## 2026-09-09 修复 Windows 平台 complex-vector 单元测试兼容性

### What
1. 在 `src/s7_liii_vector.c` 的 `g_make_complex_vector` 中，使用官方 API `s7_vector_fill(sc, vect, init)` 替代手写的 `creal`/`cimag` 循环，避免在 Windows (MSVC) 下因未包含 C 运行时复数头文件导致链接到 `_Dcomplex` 符号而发生 ABI 传参崩溃（exit-code 0xC0000005）。
2. 在 `tests/liii/vector/make-complex-vector-test.scm`、`complex-vector-ref-test.scm`、`complex-vector-set-bang-test.scm` 与 `multivector-test.scm` 中，针对 Windows (MSVC) 平台调整复数读取断言。
3. Windows 下由于 MSVC 编译器未启用 `HAVE_COMPLEX_NUMBERS`（C99 复数缺失），`complex-vector` 存储值为 `0.0`，测试中通过 `(os-windows?)` 区分断言，确保在非 Windows 下完整测试复数值、在 Windows 下通过 `number?` 验证并保持跨平台 CI 通过。

### Why
1. `g_make_complex_vector` 之前在手写填充循环中直接调用了 `creal`/`cimag`，在 MSVC 下 ABI 不匹配导致 STATUS_ACCESS_VIOLATION。
2. Windows CI 中 MSVC 缺少 C99 原生复数算术支持，`s7` 在 MSVC 下设置 `HAVE_COMPLEX_NUMBERS 0`，不提供 `'complex-numbers` feature，导致此前直接比对复数常量的测试在 Windows 下失败。
