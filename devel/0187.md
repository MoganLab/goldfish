## 5. 2026-09-22 补齐 (liii string-cursor) 库概览文档与分类索引

### 5.1 What
1. 创建 `tests/liii/string-cursor-test.scm` 作为 `(liii string-cursor)` 库的概览文档与入口测试文件。
2. 在该文件中包含：
   - 库的总体介绍与设计理念（基于游标的 UTF-8 字符串安全遍历与操作）；
   - 核心用法示例（获取起始/结束游标、前进后退、基于游标的截取与替换）；
   - 导出的所有函数分类索引（游标构造、游标移动、比较谓词、搜索、截取与折叠等）；
   - 常见场景代码示例（结合中文字符串的安全截取，避免多字节字符被截断越界）。
3. 重新生成函数索引（`bin/gf doc --build-json`），使运行 `bin/gf doc liii/string-cursor` 能正确展示模块概览和函数导航，而不再提示 `No documentation and test cases available`。

### 5.2 Why
在实际文本清洗与文本工程处理中，`string-cursor` 是处理多字节 UTF-8 字符串最安全和高频的基础库之一。然而目前仓库中仅有单个函数的子测试文件（`tests/liii/string-cursor/*-test.scm`），缺少顶层 `tests/liii/string-cursor-test.scm`。导致开发者运行 `gf doc liii/string-cursor` 时提示找不到任何文档，必须通过 `gf source liii/string-cursor` 翻阅源码来确定导出的函数签名。补齐概览文档能显著提升该库的可发现性与开发体验。

### 5.3 How
1. 参照 `tests/liii/string-test.scm` 与 `tests/liii/generator-test.scm` 的规范结构；
2. 梳理 `goldfish/liii/string-cursor.scm` 导出的 50+ 个函数，按功能域分组（游标定位与移动、谓词比较、搜索定位、裁剪与截取、折叠与遍历、转换等）；
3. 编写具有代表性的端到端使用示例与断言检查；
4. 验证 `gf doc liii/string-cursor` 能够正常输出。
