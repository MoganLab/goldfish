# (liii tui box hstack width) 模块函数索引

`(liii tui box hstack width)` 提供水平布局列宽计算算法，支持均分（auto）、固定列宽、比例分配与固定/自适应混排模式。

使用时导入：

```scheme
(import (liii tui box hstack width))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc calculate-hstack-widths
```

## 函数分类索引

### 列宽计算
- `calculate-hstack-widths` - 计算水平布局各列分配的宽度列表
- `repeat-item` - 构造包含 n 个重复元素的列表
