# (liii sys) 模块函数分类索引

`(liii sys)` 提供进程级系统信息查询能力，包括命令行参数、可执行文件路径与标准流终端检测。

## 查看函数文档

```bash
gf doc liii/sys
```

或者查看具体函数的文档和用例：

```bash
gf doc liii/sys "argv"
```

## 函数分类索引

### 一、进程信息
- `argv` - 返回当前进程的命令行参数列表
- `executable` - 返回当前运行程序的可执行文件路径

### 二、标准流终端检测
- `stdin-tty?` - 检测标准输入流是否连接到终端
- `stdout-tty?` - 检测标准输出流是否连接到终端
- `stderr-tty?` - 检测标准错误流是否连接到终端
