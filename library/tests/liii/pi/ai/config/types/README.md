# (liii pi ai config types) 模块函数索引

`(liii pi ai config types)` 定义 AI 客户端配置相关的记录类型，包含重试配置（`<pi-retry-config>`）、全局偏好（`<pi-settings>`）、凭据信息（`<pi-credential>`）及模型元数据（`<pi-model-metadata>`）。

使用时导入：

```scheme
(import (liii pi ai config types))
```

## 函数分类索引

### 核心记录类型
- `<pi-retry-config>` - 重试策略配置记录类型
- `<pi-settings>` - 客户端全局偏好配置记录类型
- `<pi-credential>` - 服务商凭据记录类型
- `<pi-model-metadata>` - 模型规格元数据记录类型
