# (liii pi ai message types) 模块函数索引

`(liii pi ai message types)` 定义消息与内容块的核心 record 类型，包括 `<pi-user-message>`、`<pi-assistant-message>` 等。

使用时导入：

```scheme
(import (liii pi ai message types))
```

## 核心记录类型

- `<pi-user-message>` - 用户消息
- `<pi-assistant-message>` - 助手消息
- `<pi-image-block>` - 图片内容块
