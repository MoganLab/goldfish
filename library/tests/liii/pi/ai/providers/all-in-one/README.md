# (liii pi ai providers all-in-one) 模块函数索引

`(liii pi ai providers all-in-one)` 提供 all-in-one 链式调度元服务商的内置配置定义及默认伪模型元数据列表。

使用时导入：

```scheme
(import (liii pi ai providers all-in-one))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc PI_ALL_IN_ONE_PROVIDER
```

## 函数分类索引

### 服务商配置与模型定义
- `PI_ALL_IN_ONE_PROVIDER` - all-in-one 服务商基础配置
- `PI_ALL_IN_ONE_BUILTIN_MODELS` - all-in-one 内置伪模型定义列表
