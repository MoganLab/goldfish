# (liii pi ai providers kimi-coding) 模块函数索引

`(liii pi ai providers kimi-coding)` 提供 Kimi Coding 服务商的内置配置定义、模型元数据及额度耗尽错误识别。

使用时导入：

```scheme
(import (liii pi ai providers kimi-coding))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc PI_KIMI_CODING_QUOTA_ERROR
```

## 函数分类索引

- `PI_KIMI_CODING_PROVIDER` - Kimi Coding 服务商基础配置
