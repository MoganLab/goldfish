# (liii pi ai) 模块索引

`(liii pi ai)` 提供 AI 消息、事件、模型配置、请求协议、重试和中止处理等标准库能力。

## 子模块索引

- `(liii pi ai abort)` - 会话级中止信号管理
- `(liii pi ai message)` - 消息与内容块
- `(liii pi ai event)` - AI 事件及序列化
- `(liii pi ai config)` - 模型、凭证和重试配置
- `(liii pi ai models)` - 模型目录与路由
- `(liii pi ai providers)` - 服务提供商注册与配额错误处理
- `(liii pi ai api)` - Anthropic、OpenAI 和 Gemini 协议适配
- `(liii pi ai dispatch)` - 按提供商分发流式请求
- `(liii pi ai cost)` - 请求费用统计
- `(liii pi ai thinking)` - 思考级别解析
- `(liii pi ai transcript)` - 请求前消息规范化

各子模块的函数文档和使用示例见对应目录下的 `README.md` 与 `*-test.scm` 文件。
