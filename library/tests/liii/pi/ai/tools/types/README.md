# (liii pi ai tools types) 模块函数索引

`(liii pi ai tools types)` 定义工具系统核心记录类型，包括工具定义（`pi-tool-definition`）、工具执行结果（`pi-tool-result`）和截断结果（`pi-trunc-result`）。

使用时导入：

```scheme
(import (liii pi ai tools types))
```

## 函数分类索引

### 核心记录类型
- `<pi-tool-definition>` - 工具定义记录类型
- `<pi-tool-result>` - 工具执行结果记录类型
- `<pi-trunc-result>` - 文本截断结果记录类型
