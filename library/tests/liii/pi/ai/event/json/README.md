# (liii pi ai event json) 模块函数索引

`(liii pi ai event json)` 提供将 `(liii json)` 解析出的 Scheme-JSON 对象反序列化为 Agent 事件 record 的接口。

使用时导入：

```scheme
(import (liii pi ai event json))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc json->pi-event
```

### JSON 反序列化
- `json->pi-event` - Scheme-JSON 对象转事件 record
