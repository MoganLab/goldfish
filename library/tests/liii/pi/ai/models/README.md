# (liii pi ai models) 模块函数索引

`(liii pi ai models)` 是模型管理门面库，聚合了内置模型目录、模型元数据解析、模型搜索匹配、模型列表展示与模型路由功能。

使用时导入：

```scheme
(import (liii pi ai models))
```

## 查看函数文档

使用以下命令查看函数文档和测试用例：

```bash
gf doc pi-resolve-model-metadata
```

## 子模块索引

- `(liii pi ai models builtin)` - 内置模型增强与补齐
- `(liii pi ai models catalog)` - 模型目录查询与合并
- `(liii pi ai models list)` - 模型列表展示与格式化
- `(liii pi ai models meta)` - 模型元数据解析
- `(liii pi ai models route)` - 模型与服务商路由派发
- `(liii pi ai models search)` - 模型分词与模糊匹配
