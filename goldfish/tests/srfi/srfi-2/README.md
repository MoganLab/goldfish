# (srfi srfi-2) 模块函数分类索引

SRFI-2 提供 `and-let*` 宏：顺序绑定变量或执行断言，
如果任一子句结果为假则立即短路返回假，否则执行主体。

它是 `and` 与 `let*` 的结合体（亦称带守卫的 `let*`）：
既具备 `let*` 的局部变量绑定能力，又具备 `and` 的条件短路能力，
避免「中间步骤失败后仍继续执行」以及「重复计算同一值」两类问题。

## 常见用法示例

```scheme
(import (srfi srfi-2))

;; 示例1：顺序绑定变量并执行主体
(and-let* ((hi 3) (ho #t)) (+ hi 1)) ; => 4

;; 示例2：条件断言子句
(and-let* (((> 2 1))) 'ok) ; => 'ok

;; 示例3：关联列表安全查询
(and-let* ((x (assq 'b '((a . 1) (b . 2))))) (cdr x)) ; => 2
```
