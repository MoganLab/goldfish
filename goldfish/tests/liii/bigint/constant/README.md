# (liii bigint constant) 模块函数分类索引

bigint constant 提供常用 bigint 常量，避免高层库之间因为常量定义产生依赖方向问题。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/bigint/constant "函数名"
```

## 函数分类索引

### 一、常量
- `bigint-zero` - 表示数值 0 的 bigint
- `bigint-one` - 表示数值 1 的 bigint
- `bigint-two` - 表示数值 2 的 bigint
- `bigint-ten` - 表示数值 10 的 bigint
