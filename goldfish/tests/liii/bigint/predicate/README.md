# (liii bigint predicate) 模块函数分类索引

bigint predicate 提供 bigint 的谓词判断过程，包括符号判断和奇偶判断。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/bigint/predicate "函数名"
```

## 函数分类索引

### 一、符号判断
- `bigint-zero?` - 判断是否为零
- `bigint-positive?` - 判断是否为正数
- `bigint-negative?` - 判断是否为负数

### 二、奇偶判断
- `bigint-even?` - 判断是否为偶数
- `bigint-odd?` - 判断是否为奇数
