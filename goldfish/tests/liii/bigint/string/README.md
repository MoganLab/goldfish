# (liii bigint string) 模块函数分类索引

bigint string 提供 bigint 与字符串、整数之间的相互转换。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/bigint/string "函数名"
```

## 函数分类索引

### 一、转换运算
- `string->bigint` - 字符串解析为 bigint（支持 2-36 进制）
- `integer->bigint` - Scheme 整数转换为 bigint
- `bigint->string` - bigint 格式化为字符串（支持 2-36 进制）
