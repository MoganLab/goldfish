# (liii bigint compare) 模块函数分类索引

bigint compare 提供 bigint 的比较过程，包括相等比较与顺序比较。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/bigint/compare "函数名"
```

## 函数分类索引

### 一、相等比较
- `bigint=?` - 判断两个 bigint 是否相等

### 二、顺序比较
- `bigint<?` - 小于比较
- `bigint>?` - 大于比较
- `bigint<=?` - 小于等于比较
- `bigint>=?` - 大于等于比较
