# (liii han-zi) 模块函数分类索引

`(liii han-zi)` 提供汉字与数值的单字符映射能力，支持通用、财务、年份三种风格，数值语义边界止于亿（10^8）。

## 查看函数文档

```bash
gf doc liii/han-zi
```

或者查看具体函数的文档和用例：

```bash
gf doc liii/han-zi "han-zi->number"
```

## 函数分类索引

### 一、汉字与数值互转
- `han-zi->number` - 将单个汉字字符映射为非负整数
- `number->han-zi` - 将非负整数按指定风格映射为单个汉字字符

### 二、判定函数
- `han-zi-number?` - 判断是否为数字汉字

## 支持范围

| 风格 | 取值 | 示例 |
| --- | --- | --- |
| 通用 `'common` | 零～九、十、百、千、万、亿 | `#\一` |
| 财务 `'financial` | 壹～玖、拾、佰、仟 | `#\壹` |
| 年份 `'year` | 〇及通用风格数字 | `#\〇` |
