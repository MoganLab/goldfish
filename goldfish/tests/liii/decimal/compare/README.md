# (liii decimal compare) 模块函数分类索引

decimal compare 提供 decimal 的比较运算，包括相等比较与顺序比较。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/decimal/compare "函数名"
```

## 函数分类索引

### 一、相等比较
- `decimal=?` - 判断两个 decimal 是否数值相等

### 二、顺序比较
- `decimal<?` - 小于比较
- `decimal>?` - 大于比较
- `decimal<=?` - 小于等于比较
- `decimal>=?` - 大于等于比较
