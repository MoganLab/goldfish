# (liii decimal advanced) 模块函数分类索引

decimal advanced 提供 decimal 的高级运算：幂、平方根，以及带 MathContext 上下文的运算。

## 查看函数文档

使用以下命令查看函数文档和测试用例：
```bash
bin/gf doc liii/decimal/advanced "函数名"
```

## 函数分类索引

### 一、幂与开方
- `decimal-pow` - 幂运算
- `decimal-sqrt` - 平方根

### 二、带上下文的运算
- `decimal-add-with-context` - 带上下文加法
- `decimal-subtract-with-context` - 带上下文减法
- `decimal-multiply-with-context` - 带上下文乘法
- `decimal-divide-with-context` - 带上下文除法
- `decimal-pow-with-context` - 带上下文幂运算
- `decimal-sqrt-with-context` - 带上下文平方根
- `decimal-abs-with-context` - 带上下文绝对值
- `decimal-negate-with-context` - 带上下文取负
- `decimal-plus-with-context` - 带上下文恒等运算
